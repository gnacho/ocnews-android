# ocnews-android

Android client for [ocnews](https://github.com/gnacho/ocnews), the RSS reader for OpenCloud.

Native Kotlin app (Jetpack Compose + MVVM). Talks to the [Nextcloud News REST API v1.3](https://nextcloud.github.io/news/api/api-v1-3/) that ocnews implements, so it works against ocnews and any Nextcloud News server.

## Status

Early. Audit and MVP spec in `docs/`.
